# 부산 공개 CCTV 위치 자료

[부산광역시_방범용 CCTV 정보](https://www.data.go.kr/data/15082060/fileData.do)의 공식 CSV 원문을 2026-10-22 01:37:30 UTC에 내려받았다. 원문 CP949 CSV, 정규화 JSON, 다운로드 응답·해시를 담은 `source-manifest.json`을 함께 보관한다. 이용허락범위는 공식 포털의 **제한 없음**이다.

- 포털 자료명 일자: **2025-12-29**. 포털 수정일: **2026-01-07**.
- 실제 다운로드 파일명에는 **20251231**이 들어간다. 이 불일치를 임의로 정정하지 않았다. 행별 기준일은 원문에 없다. 다운로드한 날을 설치정보의 기준일로 해석하면 안 된다.
- 전국 행정안전부 자료의 공식 다운로드는 이 환경에서 302 `/error.html` → 403을 반환하여 부산광역시 공식 자료를 사용했다. 전국 자료와 혼합하지 않았다.

## 단위와 검증 결과

원문 **21,060행**은 관리번호가 있는 **개별 장비 기록**이다. 대수 집계 필드는 없다. 여러 장비가 동일 좌표를 공유하며, 좌표가 다른 장비의 설치 장소가 같은지까지 확정할 수 없다.

49개 오류 좌표의 원문과 사유는 JSON의 `excluded`에 남겼다. 이 중 47행은 위·경도가 서로 바뀐 것으로 보이고, 2행은 `35.174535.1741`처럼 형식이 깨져 있다. **추정 수정·좌표 교환·주소 지오코딩은 하지 않았다.** 유한수, 위도 -90~90/경도 -180~180, 위도 34.8~35.5/경도 128.7~129.4 범위를 검사했다. 부산 행정경계 폴리곤 검증은 하지 않았으므로 경계의 정확한 소속을 보장하지 않는다.

고유 좌표 10,521개를 설치지점 수 또는 촬영 가능 범위로 표현하면 안 된다. 시설명칭과 구군은 원문대로 유지했으며, 주소·실제 운영기관은 원문에 없어서 생성하지 않았다. 제공기관은 부산광역시다.

## 식별자와 인터페이스

일반 식별자는 `public-busan-<관리번호>`다. 서로 다른 원문 기록에 같은 관리번호가 있으면, 관리번호·구군·시설명칭·장비종류·좌표의 SHA256 앞 16자를 붙여 충돌을 구분한다. 이 경우 원문 내용이 바뀌면 접미부도 바뀐다. `source_id`는 원본 관리번호, `source_row`는 원본 연번이다. 정렬·갱신으로 바뀔 수 있는 연번을 장비 식별자로 쓰지 않는다. 조회 순서는 원문 순서다.

```python
from public_catalog import list_cameras

result = list_cameras(
    bounds=(129.03, 35.10, 129.04, 35.12),  # min_lon,min_lat,max_lon,max_lat, 경계 포함
    limit=100, offset=0,
)
# {"cameras": [...], "total": <범위 필터 후 전체 개수>, "source": <출처와 품질집계>}
```

`bounds=None`은 전체 범위다. `limit`은 0~25000, `offset`은 0 이상의 정수다. 범위 필터 후 페이지를 나눈다. 반환값은 복사본이다. `cameras`의 필드는 `id`, `source_id`, `source_row`, `name`, `district`, `purpose`, `latitude`, `longitude`, `metadata_only`, `analysis_available`이다.

모든 행은 `metadata_only=true`, `analysis_available=false`다. 공개된 위치는 영상 접근 승인·실시간 연결·정상 작동·촬영 범위를 의미하지 않는다. A의 `cam-01/02/03`과 연결하거나 그 위치로 복사하지 않는다. 승인된 영상 후보 검색과 분리해서 사용한다.

원문으로부터 재생성하고 검증:

```powershell
python public_catalog.py --rebuild
python -m pytest tests/test_public_catalog.py -q
```

재생성은 다운로드를 수행하지 않는다. 저장한 원문 SHA256이 최초 다운로드 영수증과 다르면 중단한다. 새 자료를 도입할 때는 공식 출처와 컬럼·단위·좌표 품질을 다시 확인하고 영수증을 갱신해야 한다.
