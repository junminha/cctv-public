# 시민 안전 신고 앱 (Expo)

시민이 위치·사진·짧은 영상·녹음을 B 중앙 서버로 보내는 신고 앱이다. API는 `shared/API.md`의 "시민 신고 앱 확장 (v0.3)".
디자인은 Figma(사용자 확인본)를 따른다: 밤바다 해도 지도 + 등대 신호, 신고 버튼 위 "보낼 내용" 띠.

## 흐름

- 처음 한 번: 아이디·비밀번호 회원가입(이메일·전화번호 없음) → 첨부 사용 동의와 기본 체크(사진·녹음·짧은 영상).
- 로그인은 로그아웃 전까지 유지되고 토큰은 기기 보안 저장소(SecureStore)에만 둔다. 위급할 때 로그인 단계가 없다.
- 신고 화면: GPS 위치 자동 확인, 필요하면 지도에서 수정. 내용·상세 위치·발생 시각은 모두 선택이라 아무것도 적지 않아도 보낼 수 있다.
- 신고를 먼저 접수한 뒤 체크된 항목을 촬영·녹음해 올린다. 서버는 첨부를 반영해 다시 분석한다.
- 신고자는 처리 단계(접수됨 → 주변 CCTV 확인 중 → 담당자 검토 중)만 본다. CCTV 영상·분석 결과는 보지 않는다.

## 실행

```powershell
cd smartphone/reporter-app
npm install
# .env (Git 제외)
#   EXPO_PUBLIC_API_URL=https://<휴대폰이 접속할 수 있는 B 주소>
#   EXPO_PUBLIC_LOCATION_KIND=demo   # 시연 부스 웹캠은 demo 위치로 등록돼 있다. 실제 위치면 real
npx expo start            # 휴대폰 Expo Go로 QR 스캔
```

- B는 기본적으로 `127.0.0.1:8000`만 연다. 휴대폰이 닿는 HTTPS 주소(예: Tailscale)는 사용자와 정한 뒤 설정한다.
- 서버 주소·위치 종류는 앱 화면에서 바꾸지 않는다. 토큰이나 키를 `.env`에 넣지 않는다(로그인으로 발급).

## 검증

```powershell
npx tsc --noEmit
npx expo lint
npx expo-doctor
```

브라우저 미리보기(`npx expo start --web`)는 개발 확인용이다. 웹에는 보안 저장소·역지오코딩·녹음 권한이 없어
토큰은 브라우저 저장소에, 주소 대신 좌표가 보인다. 실제 휴대폰 검증을 대신하지 않는다.
