## 2. 시연 데이터 정리 (당일)

시연 신고에는 출연자의 위치(GPS 원위치 포함)·사진·목소리가 들어 있다. 발표 자료에 필요한 것만 남기고 지운다.

- B 서버를 끈 뒤 `notebook-b/central-server/runtime/`에서 정리: `attachments/`(첨부 원본), `analysis/`(분석 캐시·근거 이미지),
  `clips/`(보존 영상) 중 필요 없는 것, `central.sqlite3`의 시연 신고·계정(`reports`, `jobs`, `attachments`, `analyses`, `events`,
  `reviews`, `reporter_accounts`, `reporter_tokens`).
- 발표용으로 남길 캡처·영상은 얼굴·목소리를 출연자가 동의한 범위로만 쓴다.
- 시연용 휴대폰의 Expo Go 앱 데이터(로그인 토큰)도 로그아웃하거나 앱 데이터를 지운다.

## 3. 키·토큰 교체 (당일)

- `notebook-b/central-server/.env`의 `OPENAI_API_KEY`를 지우거나 OpenAI 대시보드에서 키를 폐기한다.
- B 토큰 재발급: `runtime/secrets.json` 삭제 후 `configure.py` 실행(관리자 화면 다시 로그인).
- A Adapter 토큰·RTSP 계정 교체는 A 담당과 함께 한다(`runtime/a-secrets.json`).

## 4. 실제 시민에게 열기 전 필수 개선 (개발)

1. **삭제·보관 기간**: 계정 탈퇴, 본인 신고·첨부 삭제 API와 앱 화면, 자동 삭제 기한(예: 30일). API는 `shared/API.md`에 먼저 기록.
2. **위치 수집 안내·동의**: 가입 또는 처음 설정에서 위치(GPS 원위치와 고친 위치)의 수집 목적·보관 기간을 알리고 동의를 받는다.
   지금 동의 문구는 첨부 자료만 다룬다.
3. **외부 전송 고지**: OpenAI 키를 쓰면 신고문·음성·사진(근거 프레임 포함)이 OpenAI로 전송된다. 시연 전에 앱 동의 문구에
   "분석을 위해 신고 내용과 자료가 OpenAI로 전송돼요"를 넣었다(2026-10-23). 정식 서비스에서는 수탁자·국외 이전·보관 기간까지 명시한다.
   기획서 "외부 API 전송 전 목적·필요성·법적 근거 검토, 최소 정보만 사용" 원칙을 따른다.
4. **아이디 안내**: 회원가입 화면에 "실명·전화번호를 아이디로 쓰지 마세요" 안내.
5. **악용 방지**: 공개 가입·신고에 현재는 주소별 횟수 제한만 있다. 장난 신고 대응(관리자 계정 정지 등)을 검토한다.
6. **촬영 대상 고지**: 사진·영상에 다른 사람이 찍힐 수 있음을 앱에서 안내한다.
